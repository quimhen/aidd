# Real-browser smoke of the compact review page (T-06)

Page: scratch project `002-aidd-hard-rules` (generated by the real `aidd review`), served from a python http.server on 127.0.0.1:8765 (stopped afterwards), Chrome via the claude-in-chrome tools.

Verified in the real browser:
- Tabs: Resumen, Preguntas, Requisitos, Casos, Tareas, Verificacion; empty tabs (Pantallas, API) absent; 19 items, one checkbox per code, no duplicate codes.
- Tab keyboard: ArrowRight/End (synthetic events) and a real ArrowLeft key press move the selected tab.
- Check + comment on a code; per-tab "Aprobar todo en esta pestana" skips SUMMARY; on Verificacion it is disabled with the visible "Cada verificacion se marca a mano..." line.
- Button reads "Guardar progreso" with V rows unchecked; click shows alert "Falta: Verificacion V-1..V-3", focuses "Aprobar V-1", status "Progreso guardado (16/19): no es una aprobacion". After checking V-1..V-3 it reads "Aprobar y guardar" (19/19).
- Download fallback (picker undefined): anchor download name `review.md`, Blob type `application/octet-stream` (anchor click and Blob were instrumented; no file was actually written to Downloads).
- Save path with a STUBBED showDirectoryPicker (in-memory folder holding a review.html with the page blob): picker called with {id:"aidd-a8f30694", mode:"readwrite"}, review.md written, `approved: true`, `format: codes-v2`, status "Saved to specs/.../review.md".

NOT verified (owner-only): the native folder picker dialog, real permission prompts, IndexedDB handle memory, a real file written to disk by the browser. The folder-validation, abort, other-spec and TypeError-retry branches are covered under node by tests/e2e_review_roundtrip.py.
